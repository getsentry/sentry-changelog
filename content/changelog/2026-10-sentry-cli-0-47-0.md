You can now triage User Feedback, download Session Replays, and list DSNs from the terminal.

[`0.47.0`](https://github.com/getsentry/toolkit/releases/tag/cli%400.47.0) was released on 2026-10-05.

## New features

- **Feedback triage:** `sentry feedback resolve`, `sentry feedback unresolve` (alias `reopen`), and `sentry feedback spam` accept the same IDs, URLs, and `@latest` selector as `sentry feedback view`. By [Miguel Betegón](https://github.com/betegon) in [#1366](https://github.com/getsentry/toolkit/pull/1366), [#1369](https://github.com/getsentry/toolkit/pull/1369), and [#1372](https://github.com/getsentry/toolkit/pull/1372).
- **Replay downloads:** `sentry replay download` saves a replay (by replay ID, trace ID, or URL) as rrweb JSON for rrweb-player or rrvideo, to `<replay-id>.rrweb.json` or the `--output`/`-o` path. By [George Gritsouk](https://github.com/gggritso) in [#1392](https://github.com/getsentry/toolkit/pull/1392).
- **DSN listing:** `sentry dsn list` shows public DSNs with key name, enabled status, and creation date for a project, a detected monorepo, or every project in an organization (`<org>/`). By [Miguel Betegón](https://github.com/betegon) in [#1365](https://github.com/getsentry/toolkit/pull/1365).

## Bug fixes

- A final 401 after transient retries is reported as an authentication error instead of `Exhausted all retry attempts`. By [Miguel Betegón](https://github.com/betegon) in [#1370](https://github.com/getsentry/toolkit/pull/1370).

## Install and upgrade

Nightly builds now install and upgrade from Toolkit. By [Burak Yigit Kaya](https://github.com/BYK) in [#1403](https://github.com/getsentry/toolkit/pull/1403).
