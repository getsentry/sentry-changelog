You can now view or explain several issues at once, see an event's attachments, and split WebAssembly debug data from the terminal. Older traces and large project lists no longer fail.

[`0.46.0`](https://github.com/getsentry/toolkit/releases/tag/cli%400.46.0) was released on 2026-10-01. It's the first release from [getsentry/toolkit](https://github.com/getsentry/toolkit/tree/main/packages/cli) and ships the changes made in getsentry/cli since 0.45.0.

## New features

- **Batch issues:** `sentry issue view` and `sentry issue explain` accept multiple issue IDs. `--web` opens the first five unless you pass `--force`, and single-issue `--json` output is unchanged. By [Miguel Betegón](https://github.com/betegon) in [getsentry/cli#1609](https://github.com/getsentry/cli/pull/1609).
- **Event attachments:** `sentry event view` lists attachment metadata with an authenticated download URL. By [Miguel Betegón](https://github.com/betegon) in [getsentry/cli#1610](https://github.com/getsentry/cli/pull/1610).
- **`sentry wasm-split`:** A drop-in port of Symbolicator's `wasm-split` for WebAssembly build IDs and debug data. By [Ana-Maria Dumitrache](https://github.com/d2anamaria) in [getsentry/cli#1589](https://github.com/getsentry/cli/pull/1589).

## Bug fixes

- `sentry trace view` finds traces older than about 1.5 days, and `sentry replay view` resolves a trace ID to its linked replay. By [Miguel Betegón](https://github.com/betegon) in [getsentry/cli#1611](https://github.com/getsentry/cli/pull/1611) and [getsentry/cli#1614](https://github.com/getsentry/cli/pull/1614).
- `sentry project list --limit` above 100 paginates instead of failing with a 400, and numeric `project:<id>` query filters are rewritten to `project_id` with a warning. By [Miguel Betegón](https://github.com/betegon) in [getsentry/cli#1606](https://github.com/getsentry/cli/pull/1606) and [getsentry/cli#1621](https://github.com/getsentry/cli/pull/1621).
- Sourcemap injection and upload add the missing runtime snippet to bundles that already have debug IDs, such as Angular 22.1 output. By [Miguel Betegón](https://github.com/betegon) in [getsentry/cli#1630](https://github.com/getsentry/cli/pull/1630).
- `sentry sourcemap upload` no longer crashes on Node.js versions before 20.15, and commands no longer crash when the working directory was deleted. By [Miguel Betegón](https://github.com/betegon) and [Burak Yigit Kaya](https://github.com/BYK) in [getsentry/cli#1643](https://github.com/getsentry/cli/pull/1643) and [getsentry/cli#1642](https://github.com/getsentry/cli/pull/1642).

## Install and upgrade

The CLI now lives in [getsentry/toolkit](https://github.com/getsentry/toolkit/tree/main/packages/cli), with releases tagged `cli@<version>`, and the installer fetches stable releases from Toolkit. By [Burak Yigit Kaya](https://github.com/BYK) in [#1354](https://github.com/getsentry/toolkit/pull/1354).

The `curl` installer checks Sentry's release registry before GitHub, so a GitHub API 403 no longer aborts installs, and fresh interactive installs start the login flow. By [Miguel Betegón](https://github.com/betegon) in [getsentry/cli#1637](https://github.com/getsentry/cli/pull/1637) and [getsentry/cli#1574](https://github.com/getsentry/cli/pull/1574).
