These changes reached the hosted Sentry MCP server at [mcp.sentry.dev](https://mcp.sentry.dev) between September 15 and September 30, 2026. New operations are available through `search_sentry_tools` and `execute_sentry_tool`.

## Manage Alerts and Metric Monitors

- **Alerts**: `create_alert_rule`, `update_alert_rule`, and `delete_alert_rule` manage conditions, notification actions, and connections to issue streams or monitors. `get_alert_options` lists the actions, integrations, and monitor sources you can use. `find_alert_rules` and `get_alert_rule` now return complete conditions, actions, and project scope.
- **Metric Monitors**: `find_metric_monitors` and `get_metric_monitor_details` show queries and Static, Percent, or Dynamic detection. `create_metric_monitor`, `update_metric_monitor`, and `delete_metric_monitor` change them.

Reads are part of the default **Inspect Issues & Events** skill. Writes require the **Manage Projects & Teams** skill and the new `alerts:write` OAuth scope, so connections authorized before this update must re-authorize. By [Miguel Betegón](https://github.com/betegon) in [#1330](https://linear.review/getsentry/sentry-mcp/pull/1330), [#1331](https://linear.review/getsentry/sentry-mcp/pull/1331), [#1313](https://linear.review/getsentry/sentry-mcp/pull/1313), [#1333](https://linear.review/getsentry/sentry-mcp/pull/1333), [#1334](https://linear.review/getsentry/sentry-mcp/pull/1334), [#1335](https://linear.review/getsentry/sentry-mcp/pull/1335), and [#1336](https://linear.review/getsentry/sentry-mcp/pull/1336).

## Link external issues

`link_issue` attaches an existing Jira, GitHub, GitLab, Bitbucket, Azure DevOps, or Sentry App ticket, or a GitHub pull request, to a Sentry issue by URL. `unlink_issue` removes the reference without deleting the ticket. Both require the **Triage Issues** skill. By [David Cramer](https://github.com/dcramer) with [Miguel Betegón](https://github.com/betegon) in [#1027](https://linear.review/getsentry/sentry-mcp/pull/1027).

## Other improvements

- `get_issue_details` now includes the suspect commit's SHA, message, author, and source. By [Hasnain](https://github.com/hasnaintypes) with [Miguel Betegón](https://github.com/betegon) in [#1339](https://linear.review/getsentry/sentry-mcp/pull/1339).
- `find_organizations`, `find_projects`, and `find_teams` page through results with `nextCursor` instead of stopping at 25. By [Max Beech](https://github.com/maxbeech) with [Miguel Betegón](https://github.com/betegon) in [#1319](https://linear.review/getsentry/sentry-mcp/pull/1319) and [#1352](https://linear.review/getsentry/sentry-mcp/pull/1352).

## Fixes

- `search_events` fails less often to generate a query: models no longer invent invalid `environment` values, and a valid query found on the final attempt is no longer discarded. By [Jamie](https://github.com/jamieQ) in [#1346](https://linear.review/getsentry/sentry-mcp/pull/1346) (with [Miguel Betegón](https://github.com/betegon)) and [#1349](https://linear.review/getsentry/sentry-mcp/pull/1349).
- `get_issue_details` and `get_sentry_resource` no longer return 404s for projects with legacy mixed-case slugs. With [David Cramer](https://github.com/dcramer) in [#1328](https://linear.review/getsentry/sentry-mcp/pull/1328).
- Codex connections no longer fail when its client metadata can't be fetched. By [Miguel Betegón](https://github.com/betegon) in [#1312](https://linear.review/getsentry/sentry-mcp/pull/1312).
- `get_alert_options` works for organizations with Sentry Apps installed. By [Miguel Betegón](https://github.com/betegon) in [#1338](https://linear.review/getsentry/sentry-mcp/pull/1338).
- `update_issue` no longer fails when a `reason` contains null characters ([#1326](https://linear.review/getsentry/sentry-mcp/pull/1326)), and mcp.sentry.dev no longer crashes in browsers without WebAssembly ([#1345](https://linear.review/getsentry/sentry-mcp/pull/1345)).

## stdio package

[`@sentry/mcp-server`](https://www.npmjs.com/package/@sentry/mcp-server) [0.40.0](https://github.com/getsentry/sentry-mcp/releases/tag/0.40.0) through [0.42.0](https://github.com/getsentry/sentry-mcp/releases/tag/0.42.0) include the Alert and Metric Monitor tools and fixes for single-tenant `*.my.sentry.io` hosts ([#1332](https://linear.review/getsentry/sentry-mcp/pull/1332), [#1341](https://linear.review/getsentry/sentry-mcp/pull/1341) by [Miguel Betegón](https://github.com/betegon)). Since 0.41.0, self-hosted connections leave Seer off by default; add `seer` to `--skills` or pass `--all-skills` to enable it. By [Denis Chistyakov](https://github.com/AerDragon) in [#1321](https://linear.review/getsentry/sentry-mcp/pull/1321). Issue linking, suspect commits, pagination, and the `search_events` fixes are not in an npm release yet.
