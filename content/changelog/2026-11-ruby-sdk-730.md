Background work fails quietly. A nightly job stops running, a new feature flag breaks checkout for some users, or jobs pile up in the queue while the web app looks fine. Version 7.3.0 of the Sentry Ruby SDK helps you catch all three.

## Know when a GoodJob cron job fails or never runs

A cron job that stops running doesn't raise an error, so you usually find out when someone notices the missing report. If you schedule jobs with GoodJob, one line now puts every cron entry under [Crons](https://docs.sentry.io/platforms/ruby/crons/) monitoring, with no changes to your jobs:

```ruby
Sentry.init do |config|
  config.enabled_patches << :good_job_cron
  # Optional: skip entries you don't want to monitor
  config.rails.good_job_exclude_cron_jobs = [:clear_cache, /\Atmp_/]
end
```

Sentry creates a monitor from each entry's schedule and time zone, and alerts you when a job fails, runs too long, or doesn't start on time. This requires `good_job` 4.0 or later.

## See which feature flags were on when an error happened

When errors spike after a rollout, the first question is which flag caused it. Record each flag your app evaluates:

```ruby
Sentry.add_feature_flag("new-checkout", true)
```

Each error then lists the flags evaluated before it, and spans record them too. You can tell at a glance whether the errors only happen with `new-checkout` on, and turn it off. See [Feature Flags](https://docs.sentry.io/platforms/ruby/feature-flags/).

## Spot jobs piling up in the queue

A job can succeed and still be late, because it sat in the queue for minutes before a worker picked it up. ActiveJob, Sidekiq, and Resque jobs now report how long they waited and how large their payload was. The [Queues](https://docs.sentry.io/product/dashboards/sentry-dashboards/backend/queues/) dashboard shows this, so you can see when your workers can't keep up before your users do.

This release also lets you pass `Sentry.logger` to libraries that log with blocks, such as Faraday's logging middleware. See the [release notes](https://github.com/getsentry/sentry-ruby/releases/tag/7.3.0) for all changes.
