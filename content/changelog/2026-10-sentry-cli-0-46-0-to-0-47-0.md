You can now triage User Feedback, download Session Replays, list DSNs, and view or explain several issues at once from the terminal.

Releases covered:

- [`0.47.0`](https://github.com/getsentry/toolkit/releases/tag/cli%400.47.0) (2026-10-05)
- [`0.46.0`](https://github.com/getsentry/toolkit/releases/tag/cli%400.46.0) (2026-10-01)

## New features

- **Feedback triage (0.47.0):** `sentry feedback resolve`, `sentry feedback unresolve` (alias `reopen`), and `sentry feedback spam` accept the same IDs, URLs, and `@latest` selector as `sentry feedback view`. By [Miguel Betegón](https://github.com/betegon) in [#1366](https://linear.review/getsentry/toolkit/pull/1366), [#1369](https://linear.review/getsentry/toolkit/pull/1369), and [#1372](https://linear.review/getsentry/toolkit/pull/1372).
- **Replay downloads (0.47.0):** `sentry replay download` saves a recording as rrweb JSON for rrweb-player or rrvideo, to `<replay-id>.rrweb.json` by default or the path set with `--output`/`-o`. By [George Gritsouk](https://github.com/gggritso) in [#1392](https://linear.review/getsentry/toolkit/pull/1392).
- **DSN listing (0.47.0):** `sentry dsn list` shows public DSNs with key name, enabled status, and creation date for a project, a detected monorepo, or every project in an organization (`<org>/`). By [Miguel Betegón](https://github.com/betegon) in [#1365](https://linear.review/getsentry/toolkit/pull/1365).
- **Batch issues (0.46.0):** `sentry issue view` and `sentry issue explain` accept multiple issue IDs. `--web` opens up to five issues unless you pass `--force`; single-issue `--json` output is unchanged. By [Miguel Betegón](https://github.com/betegon) in [getsentry/cli#1609](https://linear.review/getsentry/cli/pull/1609).
- **Event attachments (0.46.0):** `sentry event view` lists attachment metadata and an authenticated download URL. By [Miguel Betegón](https://github.com/betegon) in [getsentry/cli#1610](https://linear.review/getsentry/cli/pull/1610).
- **`sentry wasm-split` (0.46.0):** A drop-in port of Symbolicator's `wasm-split` for adding build IDs to WebAssembly modules and splitting out debug data. By [Ana-Maria Dumitrache](https://github.com/d2anamaria) in [getsentry/cli#1589](https://linear.review/getsentry/cli/pull/1589).

## Bug fixes

- `sentry trace view` now finds traces older than about 1.5 days. By [Miguel Betegón](https://github.com/betegon) in [getsentry/cli#1611](https://linear.review/getsentry/cli/pull/1611).
- `sentry replay view` resolves a trace ID to its linked replay. By [Miguel Betegón](https://github.com/betegon) in [getsentry/cli#1614](https://linear.review/getsentry/cli/pull/1614).
- `sentry project list --limit` above 100 paginates instead of failing with a 400. By [Miguel Betegón](https://github.com/betegon) in [getsentry/cli#1606](https://linear.review/getsentry/cli/pull/1606).
- Sourcemap injection and upload add the missing runtime snippet to bundles that already have debug IDs, such as Angular 22.1 output. By [Miguel Betegón](https://github.com/betegon) in [getsentry/cli#1630](https://linear.review/getsentry/cli/pull/1630).
- `sentry sourcemap upload` no longer crashes on Node.js versions before 20.15 ([getsentry/cli#1643](https://linear.review/getsentry/cli/pull/1643)), and commands no longer crash when the working directory was deleted ([getsentry/cli#1642](https://linear.review/getsentry/cli/pull/1642)).
- A final 401 after transient retries is reported as an authentication error instead of `Exhausted all retry attempts`. By [Miguel Betegón](https://github.com/betegon) in [#1370](https://linear.review/getsentry/toolkit/pull/1370).

## Install and upgrade

The CLI now lives in [getsentry/toolkit](https://github.com/getsentry/toolkit/tree/main/packages/cli), with releases tagged `cli@<version>`. The installer fetches stable releases from Toolkit and nightlies from Toolkit's GitHub Container Registry. By [Burak Yigit Kaya](https://github.com/BYK) in [#1354](https://linear.review/getsentry/toolkit/pull/1354) and [#1403](https://linear.review/getsentry/toolkit/pull/1403).
