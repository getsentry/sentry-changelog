These updates reached the hosted Sentry MCP server at [mcp.sentry.dev](https://mcp.sentry.dev) between October 28 and November 9, 2026.

## Every tool, listed directly

`tools/list` now includes every tool your connection is granted, so clients with native tool search, such as Claude Code, Codex, and Cursor, find the right one themselves. `search_sentry_tools` and `execute_sentry_tool` are gone, deprecated tools like `search_events` are no longer listed, and every tool has a display title. With [David Cramer](https://github.com/dcramer) in [#1868](https://linear.review/getsentry/toolkit/pull/1868) and [#1906](https://linear.review/getsentry/toolkit/pull/1906), plus [#1991](https://linear.review/getsentry/toolkit/pull/1991).

## Structured results

64 of 74 tools now declare an output schema and return structured content, up from 36. Their text copy is now compact JSON, which cut 11–36% of the tokens on the largest test payloads. With [David Cramer](https://github.com/dcramer) in [#2046](https://linear.review/getsentry/toolkit/pull/2046).

## New tools

- `create_monitor` creates a cron monitor for a scheduled job. It needs the **Manage Projects & Teams** permission ([#1861](https://linear.review/getsentry/toolkit/pull/1861)).
- `submit_feedback_to_sentry_team` lets your agent tell the Sentry MCP maintainers when a tool is missing, broken, or confusing ([#1755](https://linear.review/getsentry/toolkit/pull/1755)).

## Improvements

- `get_replay_details` shows a full timeline you can filter with `categories`, `startOffsetSeconds`, `endOffsetSeconds`, `limit`, and `skip`. With [David Cramer](https://github.com/dcramer) in [#1806](https://linear.review/getsentry/toolkit/pull/1806).
- `search_logs` results link to each log, pinned in Sentry. By [Josh Ghoulberg](https://github.com/JoshuaKGoldberg) in [#1699](https://linear.review/getsentry/toolkit/pull/1699).
- Time series from the `search_*` tools now point out when unintentional drops hit the same window. By [Saraj Singh Manes](https://github.com/manessaraj) in [#1725](https://linear.review/getsentry/toolkit/pull/1725).
- If you leave out `organizationSlug` and can reach only one organization, tools use that one. With [Burak Yigit Kaya](https://github.com/BYK) in [#1836](https://linear.review/getsentry/toolkit/pull/1836).
- When a client asks you to pick an account, Sentry now shows its consent screen, where you can switch accounts ([#1971](https://linear.review/getsentry/toolkit/pull/1971)).

## Fixes

- Rate-limited reads wait for Sentry's reset time and retry instead of failing. With [Burak Yigit Kaya](https://github.com/BYK) in [#1673](https://linear.review/getsentry/toolkit/pull/1673).
- VS Code Copilot can now load `create_uptime_monitor` and `update_uptime_monitor`. With [David Cramer](https://github.com/dcramer) in [#2094](https://linear.review/getsentry/toolkit/pull/2094).
- `analyze_issue_with_seer` passes your `instruction` to Seer again. By [Sebastian Shanus](https://github.com/sebastianv1) in [#1668](https://linear.review/getsentry/toolkit/pull/1668).

## Are you using the stdio MCP server?

[`@sentry/mcp-server`](https://www.npmjs.com/package/@sentry/mcp-server) [0.48.0](https://github.com/getsentry/toolkit/releases/tag/cli%400.48.0) and [0.49.0](https://github.com/getsentry/toolkit/releases/tag/cli%400.49.0) now share the Sentry CLI's login: run `npx -y @sentry/mcp-server auth login`. A target like `acme/web` limits it to one project, each call uses the stored login that knows its org, and 0.49.0 stops at startup if that org or project doesn't exist. With [Burak Yigit Kaya](https://github.com/BYK) in [#1731](https://linear.review/getsentry/toolkit/pull/1731), [#1800](https://linear.review/getsentry/toolkit/pull/1800), and [#1802](https://linear.review/getsentry/toolkit/pull/1802), and [David Cramer](https://github.com/dcramer) in [#2056](https://linear.review/getsentry/toolkit/pull/2056). Later fixes, such as [#2094](https://linear.review/getsentry/toolkit/pull/2094), ship in the next npm release.
