Version 2.71.0 of the Sentry Python SDK traces TypeSafe Jev. Each call generates a `gen_ai.evaluate` span with the model, token usage, questions and answers.

The new [`data_collection`](https://docs.sentry.io/platforms/python/configuration/options/#dataCollection) option replaces `send_default_pii`. It gives you control per data type and has more permissive defaults (available starting in version 2.70.0).
