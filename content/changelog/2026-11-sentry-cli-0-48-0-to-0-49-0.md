You can now stay logged in to several Sentry accounts, manage org auth tokens, and see how a query changes over time from the terminal.

[`0.48.0`](https://github.com/getsentry/toolkit/releases/tag/cli%400.48.0) was released on 2026-11-05 and [`0.49.0`](https://github.com/getsentry/toolkit/releases/tag/cli%400.49.0) on 2026-11-07.

## New features

- **Multiple accounts:** `sentry auth login` adds an account instead of replacing the current one. `sentry auth list` and `sentry auth switch` move between them, and commands use the account that knows the target org. With [Burak Yigit Kaya](https://github.com/BYK) in [#1526](https://github.com/getsentry/toolkit/pull/1526) and [#1528](https://github.com/getsentry/toolkit/pull/1528).
- **Org auth tokens:** `sentry token list`, `create`, and `delete` manage the tokens used for CI uploads. They need an OAuth login from `sentry auth login`, not `SENTRY_AUTH_TOKEN`; the CLI asks you to re-authorize for `org:tokens`. With [Burak Yigit Kaya](https://github.com/BYK) and [Miguel Betegón](https://github.com/betegon) in [#1647](https://github.com/getsentry/toolkit/pull/1647).
- **Issue links:** `sentry issue link <issue> <url>` attaches a tracker issue or GitHub pull request, and `sentry issue unlink` removes it. By [Miguel Betegón](https://github.com/betegon) in [#1373](https://github.com/getsentry/toolkit/pull/1373) and [#1376](https://github.com/getsentry/toolkit/pull/1376).
- **Explore over time:** `sentry explore --time-series` (`-b`) buckets an aggregate over the period and draws a chart in Kitty or Sixel terminals. By [Miguel Betegón](https://github.com/betegon) in [#1657](https://github.com/getsentry/toolkit/pull/1657) and [#1693](https://github.com/getsentry/toolkit/pull/1693).
- **Tag breakdowns:** `sentry issue tags <issue> <key>` shows a tag's top values for an issue. By [Miguel Betegón](https://github.com/betegon) in [#1636](https://github.com/getsentry/toolkit/pull/1636).
- **Dropped events:** `sentry event analytics` reports events Sentry dropped before storage, by outcome and reason. By [Saraj Singh Manes](https://github.com/manessaraj) with [Burak Yigit Kaya](https://github.com/BYK) in [#1812](https://github.com/getsentry/toolkit/pull/1812).

## Changes in 0.49.0

- `sentry init` no longer runs the remote setup wizard. It prints a guide that a coding agent follows to add Sentry to a project. By [Miguel Betegón](https://github.com/betegon) in [#1856](https://github.com/getsentry/toolkit/pull/1856).
- `createSentrySDK()` calls no longer write local state. Pass `persist: true` to keep the old behavior. With [Burak Yigit Kaya](https://github.com/BYK) in [#2074](https://github.com/getsentry/toolkit/pull/2074).

## Bug fixes

- `sentry sourcemap upload` accepts globs such as `'.next/static/**'` and handles bundles over 65,535 files. With [Miguel Betegón](https://github.com/betegon) in [#1934](https://github.com/getsentry/toolkit/pull/1934) and [#1540](https://github.com/getsentry/toolkit/pull/1540).
- `sentry release set-commits --auto` works without an `origin` remote by reading the repository from CI variables. With [Miguel Betegón](https://github.com/betegon) in [#1863](https://github.com/getsentry/toolkit/pull/1863).
- When `cli.db` can't be opened, commands use an in-memory database instead of failing, so `@sentry/bundler-plugins` no longer silently skips source map uploads. With [Burak Yigit Kaya](https://github.com/BYK) in [#2070](https://github.com/getsentry/toolkit/pull/2070).
- `brew upgrade sentry` no longer fails with `EACCES`. If Homebrew kept you on 0.47.0, upgrade to 0.49.0. With [Burak Yigit Kaya](https://github.com/BYK) in [#2077](https://github.com/getsentry/toolkit/pull/2077).

## Install and upgrade

On Windows, install from PowerShell with `irm https://cli.sentry.dev/install.ps1 | iex`. With [Burak Yigit Kaya](https://github.com/BYK) in [#1511](https://github.com/getsentry/toolkit/pull/1511).
