Version 2.75.0 of the Sentry Python SDK traces Amazon Bedrock Converse and ConverseStream calls made with `boto3`. Each call generates a `gen_ai.chat` span with the model, token usage, inputs and outputs.

The Boto3 integration is enabled automatically when `boto3` is installed. Tracing must be enabled to see Bedrock requests.
