Your agent now picks a dedicated search tool for each kind of data, searches logs with regular expressions, and can check whether Sentry dropped events before trusting a chart.

These updates shipped to the hosted Sentry MCP server at [mcp.sentry.dev](https://mcp.sentry.dev) between October 1 and October 19, 2026.

## Dataset-specific search tools

`search_events` is replaced by `search_errors`, `search_logs`, `search_traces`, `search_metrics`, `search_profiles`, and `search_replays`. Each tool searches exactly one dataset, so a log search no longer returns spans. `search_events` still works through `execute_sentry_tool` as a deprecated alias. With [Shaun Kaasten](https://github.com/skaasten) in [#1374](https://github.com/getsentry/toolkit/pull/1374).

Time series results mark buckets that are still receiving data with `*` and leave them out of the peak, so a trailing dip isn't mistaken for a real drop. By [edwardgou-sentry](https://github.com/edwardgou-sentry) in [#1441](https://github.com/getsentry/toolkit/pull/1441).

## Regex log search

`search_logs` runs Sentry regex filters such as `message://^Timeout after \d+ms//` as written instead of rewriting them into wildcards, and the agent writes one when you describe a pattern wildcards can't express. By [JoshuaKGoldberg](https://github.com/JoshuaKGoldberg) in [#1406](https://github.com/getsentry/toolkit/pull/1406) and [#1409](https://github.com/getsentry/toolkit/pull/1409).

## See which events were dropped

`find_dropped_events` shows what Sentry received but didn't store for spans, logs, metrics, or errors, by outcome and reason, alongside the accepted volume. It's part of the default **Inspect Issues & Events** skill. By [Saraj Singh Manes](https://github.com/manessaraj) in [#1410](https://github.com/getsentry/toolkit/pull/1410).

## Other improvements

- `delete_monitor_environment` removes one environment from a cron monitor. It requires the **Manage Projects & Teams** skill. By [Evan Purkhiser](https://github.com/evanpurkhiser) in [#1443](https://github.com/getsentry/toolkit/pull/1443).
- `get_sentry_resource` opens Sentry dashboard URLs. By [Sergiy Dybskiy](https://github.com/sergical) in [#1119](https://github.com/getsentry/toolkit/pull/1119).
- Generated queries use the conditional aggregate syntax that spans, logs, and metrics expect, such as `count_if` with a backtick-wrapped filter, by [William Mak](https://github.com/wmak) in [#1494](https://github.com/getsentry/toolkit/pull/1494), and skip deprecated attributes, by [Nikki Kapadia](https://github.com/nikkikapadia) in [#1440](https://github.com/getsentry/toolkit/pull/1440).
- Queries already in Sentry search syntax, such as `(level:error)` or `count():>10`, run as written. With [Burak Yigit Kaya](https://github.com/BYK) in [#1532](https://github.com/getsentry/toolkit/pull/1532) and [#1534](https://github.com/getsentry/toolkit/pull/1534).
- mcp.sentry.dev has setup instructions for the [Pi](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/mcp.md) coding agent. By [Ramiz Wachtler](https://github.com/rwachtler) in [#1397](https://github.com/getsentry/toolkit/pull/1397).

## Fixes

- `get_issue_details` no longer fails on events with empty extra context, by [Miguel Betegón](https://github.com/betegon) in [#1353](https://github.com/getsentry/toolkit/pull/1353), or with a missing or invalid date ([#1501](https://github.com/getsentry/toolkit/pull/1501)).
- Search tools no longer fail on array-type attributes ([#1273](https://github.com/getsentry/toolkit/pull/1273)) and return Sentry's error when it rejects a query ([#1253](https://github.com/getsentry/toolkit/pull/1253)).
- The server no longer advertises tool list change notifications it never sends. By [Miguel Betegón](https://github.com/betegon) in [#1317](https://github.com/getsentry/toolkit/pull/1317).

## Are you using the stdio MCP server?

There was no new [`@sentry/mcp-server`](https://www.npmjs.com/package/@sentry/mcp-server) release in this period. The latest version is still [0.42.0](https://github.com/getsentry/toolkit/releases/tag/0.42.0), so these changes are only on mcp.sentry.dev until the next npm release.
